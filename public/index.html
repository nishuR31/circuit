Direct Vanity Routes

Fetch images directly by username and extension without touching query parameters:

/:user.gif Animated GIF circuit (e.g. /torvalds.gif, /nishur31.gif)
/:user.png Crisp high-resolution PNG (e.g. /shadcn.png)
/:user.svg Scalable vector SVG (e.g. /octocat.svg)
/api/data?user=... JSON telemetry with streaks, counts, and active days

Query Parameter Customizations

Pass any combination of query parameters to /api/circuit or direct vanity routes:

Param Type Default Description
user string octocat GitHub username (public profile)
year string last last (12 months) or specific year e.g. 2025
theme string breadboard breadboard, pcb, cyberpunk, amber, matrix, solarized, monochrome
wireMode string hybrid hybrid, jumper, pcb, bus, streak
nodeStyle string led led, smd, pad, hex
density 1–4 2 Wire routing density: 1 (sparse) to 4 (ultra)
glow 0–100 70 Active node glow intensity percentage
speed string normal GIF pulse speed: slow, normal, fast
frames 8–16 10 Number of animated GIF loop frames
scale 1 or 2 1 Retina scaling multiplier for PNG output
